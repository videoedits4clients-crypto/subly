## 3. `.gitignore` review and fixes (Step 3)

Found and fixed three real gaps before any file was staged:

1. **`python/build/` and `python/dist/` were not ignored at all.** These hold PyInstaller's intermediate build cache and the frozen ~354MB `whisper-worker.exe` — without this fix, a blind `git add -A` would have attempted to commit hundreds of MB of build output, including a single ~354MB binary, into git history. Added `/python/build/`, `/python/dist/`, and `/python/*.spec` (the `.spec` file is regenerated by PyInstaller on every build, not hand-maintained).
2. **No generic database/backup-snapshot pattern existed.** Only `/prisma/dev.db` was specifically ignored; a real stray file at the repo root, `UsersUserAppDataRoamingsubssubly.db.bak-pre-p8-multi-caption-qa` (an empty, 0-byte leftover QA marker from much earlier in this project's history — see `research/p19_14_final_packaged_release_closure_report.md` for the same class of file), was untracked and would have been swept into the commit. Added generic `*.db`, `*.db-journal`, `*.db-shm`, `*.db-wal`, `*.db.bak*` patterns, with an explicit `!/prisma/template.db` exception for the one real, required build asset (the packaged app's empty-schema template database).
3. **The pre-existing `/build` rule silently excluded a real source file.** `build/icon.svg` is the actual app-icon source `package.json`'s `build.win.icon` config points at — not build output — but the generic create-next-app boilerplate `/build` rule excluded the whole directory. Fixed by changing to `/build/*` (so the directory stays traversable) plus `!/build/icon.svg` (git cannot re-include a file whose *directory entry itself* is excluded, only one matched by its own pattern — this is why the straightforward `!/build/icon.svg` addition didn't work until the directory-level exclusion was narrowed).

Also added `/.claude/` (this session's own agent tooling config — a dev-server launch shortcut and a scheduler lock file, neither sensitive, but not SUBLY product source either).

Verified every fix directly with `git check-ignore` before proceeding, and confirmed the three massive pre-existing research benchmark datasets (`research/hinglish_benchmark/` ~1GB, `research/gujarati_fleurs_lora/` ~5.2GB, `research/hindi_benchmark/` ~46MB) were **already** excluded by their own pre-existing nested `.gitignore` files (each a blanket `*` rule) — no action needed there; confirmed via `git add -A --dry-run` producing zero matches from any of the three directories.

Final dry-run: **426 files, ~6MB total** — no unexpectedly large file, no build output, no ignored-directory leakage.

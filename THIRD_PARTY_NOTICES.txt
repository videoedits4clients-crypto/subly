SUBLY — Third-Party Notices
============================
This file lists the significant third-party components bundled in or required
by the SUBLY Windows desktop build, and the license terms that apply to each.
It is not legal advice — it is an honest inventory of what is being
distributed, produced by inspecting each component directly rather than
assuming.

--------------------------------------------------------------------------
FFmpeg / FFprobe  —  GPL v3  (NOT LGPL — verified, see below)
--------------------------------------------------------------------------
Bundled via the npm packages `ffmpeg-static` (v5.3.0) and
`@ffprobe-installer/ffprobe` (v2.1.2), which download a prebuilt Windows
binary from the gyan.dev "essentials" FFmpeg build
(https://www.gyan.dev/ffmpeg/builds/).

Verified by running the bundled `ffmpeg.exe -version` directly: its own
reported build configuration includes `--enable-gpl` together with GPL-only
codecs (`--enable-libx264 --enable-libx265 --enable-libxvid` among others).
A build compiled with `--enable-gpl` is licensed under the GPL (version 2 or
later, effectively GPLv3 given `--enable-version3`), NOT the LGPL — the LGPL
option only applies to a build compiled WITHOUT `--enable-gpl`, which this is
not.

What this means for SUBLY: FFmpeg/FFprobe are invoked as separate child
processes (via `ffmpeg-static`/`fluent-ffmpeg`), never linked into SUBLY's own
compiled code — the standard "mere aggregation via separate process, not a
derivative work" interpretation that most software bundling FFmpeg.exe relies
on. This notices file, and access to the exact matching FFmpeg source (gyan.dev
publishes source alongside every build), fulfill the GPL's attribution/source-
availability expectations for the GPL-licensed binary itself. This is NOT a
substitute for a lawyer's review before commercial distribution — the
separate-process argument is the common industry practice, not a guarantee.

Full GPL v3 text: https://www.gnu.org/licenses/gpl-3.0.html
Matching FFmpeg source: https://www.gyan.dev/ffmpeg/builds/ (see the
"release-essentials" build notes for the exact source revision).
